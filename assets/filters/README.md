# Bundled network filters

EasyList and EasyPrivacy snapshots from 27 October 2026, obtained from their official distribution URLs:

- https://easylist.to/easylist/easylist.txt
- https://easylist.to/easylist/easyprivacy.txt

Original headers and license notices are retained in the files. Drift uses Ghostery's network filter engine, keeps bundled filters for offline startup, and attempts weekly updates from those two URLs. Cosmetic/scriptlet injection is not enabled.
